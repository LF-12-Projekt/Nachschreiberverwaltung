# Aufsetzen des Frontend Projekts


## Voraussetzungen:

[Node.js](https://nodejs.org/en) - LTS version installieren

## Schritte 

1. Ins "Nachschreibeverwaltung" Verzeichnis gehen
```
cd frontend/nachschreibeverwaltung
```
---
2. Angular CLI installieren
```
npm install -g @angular/cli
```
---
3. Yarn installieren:
```
npm i -g yarn
```
---
4. Yarn ausführen
```
yarn
```
4. App starten/bauen. Unter http://localhost:4200/ im Browser findet man die App.
```
yarn start
```
